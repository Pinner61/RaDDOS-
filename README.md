# RaDDOS

RaDDOS is a personal cybersecurity simulation project maintained by Tejas Sharma and a collaborator.

This project is based on the original Raven codebase and is being modified for learning, experimentation, and feature development. Our goal is to build it into a clearer, more polished, and more personalized project with improved documentation, interface updates, and custom simulation features.

## Project Goals

- Improve the project branding and documentation
- Add clearer setup and usage instructions
- Refactor parts of the codebase for readability
- Add custom cybersecurity simulation features
- Build this into a strong personal portfolio project
